# MusicGo 功能图

> 原生 GPU 音乐播放器 · Go + MyGo · 无 Electron / 无 WebView / 无 Node.js 运行时
>
> 图源：[`diagrams/feature-map.mmd`](diagrams/feature-map.mmd) · 渲染脚本见文末

当前功能入口与行为以本页清单和上述 Mermaid 图源为准。

## 功能分区

### 发现音乐

- **每日推荐**：优先通过内置酷狗插件获取，支持匿名及已登录账号；接口不可用时回退到关键词聚合。匿名结果不能视为个性化推荐。

| 功能 | 说明 | 实现位置 |
| --- | --- | --- |
| 发现音乐 | 每日推荐优先使用内置插件；其余分类通过音源插件搜索聚合 | `views/recommend.go` |
| 每日推荐 / 热门 / 新歌 / 经典 / 轻音乐 | 五个分类 Tab，按对应能力或关键词获取歌曲 | `views/recommend.go` |
| 快捷搜索标签 | 周杰伦 / 林俊杰 / 陈奕迅 等一键跳转到搜索页 | `views/recommend.go` |

### 为你推荐

- 从本地收藏、最近选择过的歌曲或用户输入的歌手扩展候选，保留可核实的推荐理由；不需要登录。
- 三封套主视觉、最多六首预览、完整批次列表，以及喜欢的歌手的其他作品。内容区内部宽度达到 800 时预览使用双列，否则使用单列。
- 音源选择同时影响封套、曲目和播放集合；换一批只更新推荐，不改正在播放的队列。
- 支持熟悉/均衡/新鲜偏好、探索关键词、暂不推荐及撤销；偏好、批次和排除项继续使用现有持久化格式。
- 导航使用独立的 `personalized` 路由；旧排行榜页面已移除，插件榜单接口仍保留兼容能力。

### 页面与曲目操作

- 普通页面统一边距、24 字号标题及返回按钮；两个推荐页保留各自的主视觉和内容布局。
- 普通歌曲列表和推荐预览共用 64 高、44 封面的行绘制；操作命中区为 32×32，悬停及键盘聚焦时显示。
- 发现页每帧读取一份推荐快照，音源筛选后 Hero、列表和“播放全部”绑定同一集合；更新失败保留已有结果并提供重试。
- 曲目列按主内容区可用宽度收缩；隐藏的来源、时长等信息仍可通过提示查看。已下载歌曲保留文件大小、播放及删除操作。
- 设置面板可滚动、工具栏可换行，账号歌单和插件卡片按内容宽度调整列数。
- 发现歌曲、远端合集、下载任务与已下载歌曲使用 MyGo 原生虚拟列表，只构建可见区域附近的行；合集定位当前歌曲使用列表自身的定位接口。
- 顶栏后退优先返回当前详情的父页，其余页面返回发现音乐；发现首页后退禁用，无回调时不显示前进按钮。

### 搜索

- **跨插件并发搜索**：所有插件同时发起请求，结果合并；单个插件失败不影响整体
- **取消旧请求**：提交新关键词或切换搜索类型会取消上一轮请求；退出前也会取消搜索及详情加载，旧请求和旧插件世代的结果不会回写界面。
- **四种搜索类型**：单曲 / 专辑 / 歌单 / 歌手，对应插件的 `supportedSearchType`
- **酷狗公开歌单**：支持搜索和分页查看歌单中的歌曲；可播放性取决于歌曲权限和音源状态。
- **原生详情**：专辑、歌单、歌手结果打开详情页，歌手默认展示歌曲作品；支持分页、返回原搜索和世代号防串。歌单缺少详情接口时回退 `importMusicSheet`，不支持时明确提示；容器结果不进入歌曲播放、收藏或下载操作
- **按音源来源筛选**：结果按插件平台分栏，可只看某一个源
- **统一搜索快照**：关键词、类型、音源计数和可见结果来自同一份只读快照；来源缺失的结果使用统一显示和筛选规则，切换筛选后从列表顶部显示。
- **失败恢复**：区分搜索超时、未安装音源、音源已更新及正常空结果；失败可直接重试，单曲、专辑、歌单和歌手的空结果均有明确提示。
- 搜索和歌单详情的歌曲菜单支持下一首播放、加入本地歌单；远端详情可筛选已加载歌曲并定位当前歌曲。
- **世代号防串**：后发起的搜索先返回时，先发起的旧结果会被丢弃（`seq`）

### 播放

| 功能 | 说明 |
| --- | --- |
| 播放 / 暂停 / 上下首 | 状态机 `Stopped · Loading · Playing · Paused` |
| 播放模式 | 顺序 / 列表循环 / 单曲循环 / 随机 |
| 进度条拖拽定位 | 拖动时预览，松手才真正 seek（避免频繁重启解码器） |
| 音量 | 滑块与引擎双向同步，热键改动也会回写滑块 |
| 播放队列 | 虚拟歌曲列表，打开定位当前项；支持播放/暂停、移除、拖动及菜单排序，清空同时停止播放 |
| 均衡器 + 播放速度 | 4 段 biquad 峰值滤波（60Hz/250Hz/1KHz/4KHz）+ 0.5×–2× 变速 |
| 多音源自动换源降级 | 当前插件取不到音源时，自动用曲名+歌手到其它插件换源 |
| 播放音质 | 设置默认音质并从播放栏切换；按请求音质隔离缓存，已知降级时在播放栏提示。插件未报告实际音质时只显示请求档位。 |

- 进度条悬停显示目标时间；音量图标支持静音/恢复，鼠标停留在音量控件上可用滚轮调节。
- 队列按独立条目标识操作，重复歌曲各自保留；“下一首播放”优先复用队列内的非当前歌曲，在随机和单曲循环下也生效。单曲循环的自然结束重播本曲，手动“下一首”则前进。
- 移除当前项时，播放中继续下一项、暂停中保持暂停；清空队列同时取消加载并清理当前歌曲。直接播放已下载文件也加入同一队列。
- 队列操作与会话兼容说明见 [播放队列重构](PLAYBACK_QUEUE.md)。

### 歌词

- **全屏歌词页**：大封面 + 逐行滚动，当前行放大高亮
- **大字歌词同步**：插件提供 LX 或增强 LRC 的字词时间时按真实时间高亮；普通 LRC 按句切换并短暂淡入。暂停、倍速与拖动共用播放器进度，不估算逐字演唱时间。
- **酷狗逐字歌词**：内置概念版插件优先获取 KRC，在后台用 Go 解码并保留字词起点、持续时间；缺失、损坏、超时或无可用逐字时间时自动回退普通 LRC。
- **桌面悬浮歌词窗**：独立透明置顶窗口，可拖动，显示当前行 + 下一行
- **桌面歌词调整**：窗口内可调整字号、默认色和高亮色并锁定位置，设置会保存；具备真实字词时间时逐字高亮。位置锁定不等于鼠标穿透。
- **歌词翻译 / offset 校正**：`[offset:+500]` 对全部行生效（两遍扫描，先读元数据再解析时间轴）

### 媒体库

- 我喜欢（收藏） / 最近播放 / 自建歌单
- 列表过滤：按标题、歌手、专辑实时筛选，显示「筛选出 N 首（共 M 首）」
- 播放历史去重：同一首歌再次播放会置顶而不是重复

### 下载管理

- 下载任务支持暂停、继续、删除和批量控制；“全部继续”也恢复已取消任务。删除任务后释放其文件名占用，已保留的文件仍不会被覆盖。
- 已下载列表显示文件大小；文件缺失时显示恢复入口，可沿用原任务与音质重新下载。“播放全部”跳过缺失文件，没有可播放文件时禁用。
- 文件可用性在后台维护并触发界面更新，绘制和播放按钮状态不直接读取磁盘。
- 下载记录保存失败后保留待写状态，每两秒重试，并合并同一任务的旧进度记录；退出时再尝试保存，仍失败则记录日志。
- 拒绝空响应作为下载完成，断点续传校验响应范围和长度；任务卡片使用任务 ID 保持滚动位置与控件身份。

### 插件生态

- **本地安装**：输入 `.js` 绝对路径，或从网络 URL 下载安装
- **音源测试**：逐插件测试「能否搜索 + 能否解析出可播放地址」
- **一键清理失效插件**：**需二次确认**，且只移除「确实音源失效」的插件；网络不通时不会误删
- **插件卸载**：只删除该插件自己的文件，不影响其它插件
- 兼容 CommonJS 与 ESM（`export default`）两种写法
- **榜单接口兼容**：插件运行时与管理器保留 `getTopLists` / `getTopListDetail`；当前应用不提供独立排行榜页面。

### 系统集成

- 系统托盘菜单（播放控制 / 显示隐藏 / 切换桌面歌词 / 退出）
- 关闭主窗口后继续后台播放；从托盘恢复窗口，选择「退出 MusicGo」才保存状态并退出。托盘创建失败时，关闭改为最小化到任务栏。
- 全局快捷键：播放暂停、上下首、音量增减（Wayland 下由桌面 Portal 绑定）
  - **默认关闭**，在「偏好设置 → 快捷键设置」里开启。Wayland 下桌面要用户确认
    才会绑定，每次启动都弹窗很打扰，所以由用户自己决定何时启用
- 播放通知：默认关闭，可在「偏好设置 → 音频效果」中开启；当前歌曲实际开始播放后通过 MyGo 原生通知发送，加载失败不通知
- 系统媒体控制：通过 MyGo 原生 `NowPlaying` 对接 Linux MPRIS、macOS Now Playing 和 Windows 系统媒体控件，支持播放/暂停、停止、上下首与定位；音量、速度和循环模式在应用内调整
- 原生界面缩放：Ctrl/Cmd + `+` / `-` 调整至 80%–150%，`0` 恢复原始大小
- 数据备份：导出 / 导入 **MusicFree 兼容** 的 JSON（歌单 + 收藏 + 历史）

### 偏好设置

五个页签：**主题外观**（深色 / 浅色 / 已保存的自定义主题，实时切换）、**音频效果**（播放速度 0.5–2.0x、
音量、4 段均衡器 ±12 dB、切歌通知）、**快捷键设置**（全局快捷键开关、绑定状态及按键说明）、
**下载设置**（目录、并发数、歌词保存）和 **数据备份**（导入导出）。

页面直接从页签开始，不显示重复的“偏好设置”大标题。桌面歌词相关控件已从设置页移除。

插件不在这里管理：侧边栏「扩展中心 → 插件管理」是唯一的入口，功能也更全。

选择内置主题会保留自定义配色，可随时选回；旧配置没有显式主题选择标记时沿用原有优先级。

## 主流程

```
插件生态  →  搜索 / 发现  →  播放  →  歌词  →  媒体库  →  再次播放
```

## 对标增强

- 播放会话保存毫秒进度与随机访问历史；每 30 秒及操作变化后台保存，退出前取得最终快照。重启保持暂停，点击播放才加载音频。
- 音频缓存默认 512 MiB，完整文件复用并校验 SHA-256；ffmpeg/ffprobe 和内置解码共用顺序下载，远处定位另走 Range。音频效果设置可关闭、调整容量和清理，正在读取的文件释放后删除。
- 暂停 180ms 淡出、恢复 260ms 淡入；定位先做 30ms 短暂停顿，连续操作以最新意图为准，不改变用户音量。
- 歌词背景在新封面加载前保持连续，就绪后 700ms 交叉淡变；普通歌词 420ms 轻微上浮渐入，手动 seek 不重放入场，减少动态效果时直接切换。
- 全局搜索保留最近 20 条记录，去重置顶并跨重启保存；输入时仅筛选本地历史，支持上下键、Enter、Esc 和清空历史，不产生建议网络请求。
- 封面获取与背景处理共用最多 4 个后台任务名额；满额时不创建等待 goroutine，任务完成释放名额后重绘，当前页面再申请尚未加载的图片。
- 退出时取消封面网络请求、停止接收新图片任务并等待在途任务结束，随后释放空闲连接；后台图片任务不再向已关闭的界面请求重绘。
